# Brand logos

Drop a file here named after the brand's slug and the rail picks it up on the
next page load. Nothing else to configure.

    seiko.svg          ->  shows on the SEIKO disc
    armani-exchange.svg
    michael-kors.png

Order of preference: `.svg`, then `.png`, then `.webp`.

What works best on the disc:

* **SVG, one colour, dark.** The disc is a pale plaque in every theme precisely
  so a dark mark always reads. A white or light logo will disappear.
* **Transparent background.** A logo on its own white box shows as a square
  inside the circle.
* **Trim the whitespace.** The disc already supplies 30px of padding; a file with
  its own generous margins ends up looking tiny.
* **Wordmark, not lockup.** The brand name alone reads at 110px wide. A logo with
  a tagline or a registered-trademark line under it does not.

Ask the distributor for the brand asset kit — authorised dealers are normally
given one, and it will contain exactly this: a one-colour vector wordmark.

Until a file is here, the brand is set in type, which is deliberate: type beats a
low-resolution logo pulled off a search result.
